# Bible corpus provenance

`bibles.json` contains complete or near-complete public-domain translation data for offline display and search. Corpus is 22.7 MB uncompressed. We retain the source translation metadata and bundle an aligned reference table.

| Code | Edition | Language | Source/license |
|---|---|---|---|
| KJV | King James Version (1769 standard text) | English | [Midvash bible-data](https://github.com/midvash/bible-data), metadata identifies public domain worldwide |
| WEB | World English Bible | English | [Midvash bible-data](https://github.com/midvash/bible-data); [eBible.org terms](https://ebible.org/web/) identifies public domain |
| ASV | American Standard Version | English | [Midvash bible-data](https://github.com/midvash/bible-data), metadata identifies public domain |
| RVR09 | Reina-Valera 1909 | Spanish | [BibleAquifer ReinaValera1909 release](https://github.com/BibleAquifer/ReinaValera1909/releases/tag/v2026-09-18) marks the text CC0/public domain; [Open.Bible catalog](https://open.bible/bibles/reina-valera-1909) lists the edition as Public Domain |
| ALMEIDA | Almeida 1819 (Bíblia Livre) | Portuguese | [Midvash bible-data](https://github.com/midvash/bible-data), metadata identifies the 1819 edition as public domain |

The source repositories and corpus are independently licensed from this app. This file records the upstream provenance; review source notes before redistributing the bundled dataset. No NIV, ESV, NLT, NKJV, or CSB text is bundled. Those translations require publisher or authorized-platform terms for each use case.

The aligned table contains 31,102 references from KJV. Included source counts are 31,102 KJV, 31,095 WEB, 31,086 ASV, 31,084 RVR09, and 31,102 Almeida verses. Rows missing in an edition are blank for that edition.
